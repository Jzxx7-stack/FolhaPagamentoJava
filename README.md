# Sistema de Folha de Pagamento em Java

Projeto desenvolvido em Java para cadastrar colaboradores e calcular a folha de pagamento de acordo com o tipo de vínculo.

O sistema possui três tipos de colaboradores:

- Colaborador Padrão: recebe apenas o salário base.
- Colaborador Comissionado: recebe o salário base mais uma comissão calculada sobre o valor das vendas.
- Colaborador Produção: recebe o salário base mais um valor de produtividade calculado de acordo com a quantidade de peças produzidas.

O salário base utilizado para todos os colaboradores é de R$ 2.000,00.

O programa possui um menu interativo que permite cadastrar colaboradores, gerar a folha de pagamento, visualizar o resumo da folha e encerrar o sistema.

Também foram aplicados conceitos de classes, objetos, métodos, herança, encapsulamento, ArrayList, estruturas de decisão, estruturas de repetição e entrada de dados com Scanner.
